Arquitectura Completa de MyWallet

Aplicación de escritorio corporativa para finanzas personales diseñada bajo un enfoque local-first: la interfaz en React corre dentro de una ventana aislada de Electron, consume un backend Express embebido en 127.0.0.1 y guarda toda la información en una base de datos SQLite persistente en la carpeta del usuario.

Principios de Diseño Clave

  • Patrón por Capas en Backend: Cada dominio vive en server/src/modules/<nombre>/ separado en routes → controller → service → repository con esquemas Zod dedicados.
  • Branding Reemplazable: Los recursos gráficos (logo.svg, hero-illustration.svg, empty-state.svg) viven en client/public/brand/ y se centralizan en config/brand.ts.
  • Asistente Inicial Bloqueable: Al abrir por primera vez sin datos, solo se muestra OnboardingWizard. Al finalizar, se persiste onboarding_completed = 1 en app_settings y desaparece para evitar duplicar o dañar cifras.
  • Checklist Irreversible de Esenciales: Vivienda, Salud, Alimentación, Servicios y Transporte generan cuotas mensuales en essential_payments. Al marcar como pagado se crea el gasto automáticamente y queda bloqueado.
  • Subcategorías e Inversiones: Cada categoría (incluyendo Inversiones y Suscripciones) soporta subcategorías con valor unitario × frecuencia mensual que sincronizan automáticamente el presupuesto padre.
  • Formato COP en Vivo: Todos los montos numéricos usan FormattedNumberInput para mostrar separadores de miles mientras se escribe.
Para futuros agentes IA: Este repositorio incluye el archivo docs/architecture.json con el contrato técnico completo, invariantes críticas y guía paso a paso para añadir nuevas features sin romper el empaquetado.

5 Vistas Principales + Onboarding
Primera Ejecución

OnboardingWizard

Encuesta guiada de ingresos (sueldo/freelance), planes esenciales con frecuencia, gastos/subcategorías, deudas y metas. Se oculta permanentemente al completarse.

Tab 1 · dashboard

¿Cuánto me queda? (DashboardView)

Saldo disponible, presupuesto diario restante, KPIs con variación mensual, regla 50/30/20, insights automáticos, checklist de esenciales y gráficos Recharts.

Tab 2 · transactions

Movimientos (TransactionsView)

Libro mensual de ingresos y gastos con filtros por tipo, categoría y texto, edición/eliminación, TransactionModal rápido y CategoryModal.

Tab 3 · budgets

Presupuestos (BudgetsView)

Límites mensuales por categoría, alertas al 80% y 100%, editor de subcategorías (valor × frecuencia/mes), copia del mes anterior y checklist de esenciales.

Tab 4 · goals

Metas y Deudas (GoalsAndDebtsView)

Vista con pestañas para metas de ahorro (aportes, retiros e historial) y gestión de deudas con priorización método avalancha y abonos vinculados a gastos.

Tab 5 · reports

Reportes (ReportsView)

Descarga directa de reporte corporativo en PDF y libro Excel de 7 hojas, más comparativa visual y tabular contra el mes anterior.

GitHub Actions + Auto-Updater

🔒 Endurecimiento de Seguridad

  • nodeIntegration: false + contextIsolation: true + sandbox: true en la ventana principal.
  • Puente mínimo: Solo se expone window.mywalletDesktop vía contextBridge (versión, ruta DB, abrir carpeta de datos y estado de actualizaciones).
  • Navegación restringida: Bloqueo total de popups (setWindowOpenHandler), etiquetas <webview> y orígenes externos.
  • Datos blindados: SQLite reside en userData/data/mywallet.db y deleteAppDataOnUninstall: false protege las finanzas al actualizar o reinstalar.

📦 Pipeline de Compilación y Publicación

  • Frontend: vite build compila React a client/dist/ (con base: './').
  • Bundles Autocontenidos: scripts/build-desktop.cjs empaqueta con esbuild el backend en server/dist/index.js (dejando better-sqlite3 externo y copiando fuentes .afm de PDFKit) y compila electron/dist/{main,preload}.js.
  • Instaladores: electron-builder.yml genera MyWallet-Setup-1.0.0.exe (Windows NSIS x64) y .dmg/.zip (macOS arm64 + x64).
  • CI/CD Automático: .github/workflows/build-and-release.yml compila ambos sistemas en la nube al hacer push de un tag v* y publica en GitHub Releases.
